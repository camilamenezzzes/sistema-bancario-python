# Sistema Bancário em Python

Projeto desenvolvido durante o Bootcamp de Back-End com Python.

## Sobre o projeto

Este sistema bancário foi criado utilizando Python e executado no terminal.  
O objetivo do projeto é simular operações bancárias básicas, praticando conceitos fundamentais da linguagem.

## Funcionalidades

- Depósito
- Saque
- Visualização de extrato
- Limite de saque diário
- Controle de saldo

## Regras do sistema

- Máximo de 3 saques por dia
- Limite de R$ 500,00 por saque
- Não permite saque sem saldo
- Não permite valores inválidos

## Tecnologias utilizadas

- Python

## Aprendizados

Durante o desenvolvimento deste projeto foram praticados conceitos como:

- Estruturas condicionais
- Estruturas de repetição
- Variáveis
- Manipulação de strings
- Entrada e saída de dados
- Lógica de programação

## Como executar

1. Clone o repositório
2. Abra o terminal na pasta do projeto
3. Execute o comando:

```bash
python main.py
```
